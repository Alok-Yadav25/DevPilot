Requested services: Cloudflare Pages frontend, Render Free API, Neon PostgreSQL and a separate public GitHub Actions sandbox. ChatGPT/OpenAI hosting is prohibited.

## Preparation status

- Frontend production build and local desktop/mobile browser flows pass.
- `render.yaml` describes the Free API service. It uses the Docker build only to package the trusted API; test execution is dispatched to GitHub Actions.
- `app.serve` validates production settings, applies Alembic migrations, and starts one API process on Render's `PORT`. Migration failure prevents startup. Free Render services do not offer a pre-deploy command.
- PostgreSQL URIs copied from Neon are normalized to the installed psycopg driver. Use a pooled endpoint for normal API traffic and require SSL.
- `API_ACCESS_TOKEN` is generated by Render. Provider keys and database credentials are private runtime environment variables, never frontend build variables.
- Set `ALLOWED_ORIGINS` and `CORS_ORIGINS` to the exact published frontend origin. Set `VITE_API_URL` to the published API origin when building the frontend.
- The selected source repository's existing MIT licence and history must be preserved; no force push is required.
