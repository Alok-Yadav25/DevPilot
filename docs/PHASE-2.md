# Phase 2 — durable recovery

Changed: `agent/graph.py` persists after each completed node and reconstructs an ephemeral checkout at the tested SHA; the saved state excludes workdir paths. `github/clone.py` adds pinned-SHA recovery. `db/models.py` and migration `0002_recovery` add checkpoints, remote jobs, cancellation state and expiring database leases. `service.py` acquires leases, heartbeats, recovers active runs, restores approval waits without external requests, and bounds concurrent leases (Postgres advisory transaction lock). Shutdown pauses remote jobs instead of cancelling them. `main.py` runs periodic recovery/retention cleanup. `sandbox/github_actions.py` stores remote IDs, results and dispatch intent; resumes polling existing IDs and reconciles ambiguous dispatches by stable workflow name. `github/pr.py` reconciles an existing approved branch/PR rather than overwriting it. Existing temp cleanup remains active.

Tests added: nine node-boundary power-loss simulations with scripted model/test outcomes and temporary Git repositories; database lease expiration/terminal-state test; mocked remote reattachment without dispatch; mocked lost-PR-response reconciliation; in-process approval-wait preservation. Default suite: 132 passed, 5 local-container integration tests skipped. Ruff/mypy pass. SQLite migration smoke check is local; Postgres lease behavior is not live-verified.

Verified live: none. No API-kill test against actual Actions or real Postgres has run. This phase's live acceptance condition remains unmet. Unknown dispatch responses fail safely if reconciliation cannot locate a named run; no blind retry. Worker leases expire after 45 seconds and heartbeat every 10 seconds. Availability is bounded by the global run timeout, which includes time lost to restart.

Risks: remote cleanup/reconciliation, process-kill behavior and Postgres concurrency still require Phase 5 evidence. Retention removes only patch branches referenced by local durable run records, not arbitrary sandbox branches. Groq key rotation remains unconfirmed. No publication or deployment was performed.
